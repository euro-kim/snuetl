# SNUETL for Windows 0.9.4

The mini panel now shows useful course updates in four tabs: Alerts, Announcements, Deadlines, and Files. Announcement cards include the class, title, and message preview; clicking opens the announcement on eTL. Deadline cards show due dates and missing work, with submitted assignments excluded. Routine Markdown copy saves and removals no longer clutter the feed.

The installer no longer asks you to select an additional login package. Use automatic login inside SNUETL to download the latest available browser component, follow its progress, and sign in. The responsive login progress and cancellation fixes from 0.9.3 are included.

Run `SNUETLSetup-0.9.4.exe` to upgrade. Existing settings, credentials, and course files are preserved. This installer reuses the existing 0.9.0 sign-in browser ZIP; there is no new browser release.
