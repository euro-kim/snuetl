# SNUETL 0.9.7

Windows에서 수업 자료와 알림을 더 편하게 확인할 수 있도록 한국어 UI와 기본 아이콘을 개선했습니다.

## 변경 사항

- 학습 현황, 공지사항, 마감 일정, 파일 활동, 설정, 트레이 메뉴를 한국어로 표시합니다.
- 계정 연결·동기화·업데이트 안내를 짧게 정리하고 장식적인 설명을 제거했습니다.
- 기본 SNU 로고에 둥근 흰색 바탕과 투명 모서리를 적용했습니다. 기존 SNU 아이콘도 업데이트 후 재생성합니다.
- Windows 로컬 소스 설치의 파일 URI 변환 오류를 수정했습니다.

## 설치

`SNUETLSetup-0.9.7.exe`를 실행해 업데이트하세요. 계정, 설정과 수업 자료는 유지됩니다.
자동 로그인 구성 요소는 기존 0.9.6 릴리스를 별도로 사용합니다. 이 Windows 설치 파일은 서명되지 않았습니다.

수동 동기화와 1~1,440분 간격의 자동 확인을 지원합니다. 온라인 전용 파일은 열 때 내려받으며,
서버 푸시 방식의 실시간 동기화나 eTL로의 업로드는 지원하지 않습니다.
Linux CLI, SQLite 조회, JSON 기반 에이전트 인터페이스와 Linux Docker 배포는 저장소의 플랫폼별 안내를 참조하세요.

## 검증

- .NET 클라이언트 테스트 48개 통과.
- Python Windows 백엔드·데스크톱 도우미·Canvas API 테스트 및 패키지 스모크 검사 통과.
- Windows 파일 URI 업데이트 회귀 테스트 2개 통과.
- 7개 크기 아이콘의 투명 모서리·불투명 중심, 한국어 UI 렌더링, Cloud Files 주문형 다운로드와 제거 시 로컬 파일 보존 통합 검사 통과.
- 전체 Linux Python 테스트는 이 Windows 호스트에서 `fcntl`·`termios`가 없어 수집할 수 없었습니다. Linux/Docker 실기동은 이번 릴리스에서 재검증하지 않았습니다.

본 프로젝트는 서울대학교의 공식 제품이 아닌 실험적 개인 개발 소프트웨어입니다.
